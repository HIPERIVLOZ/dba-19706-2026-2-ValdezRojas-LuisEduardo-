# Actividad 5 - Análisis de una finalidad secundaria

## Objetivo

Analizar si la empresa puede utilizar los datos de sus clientes para enviar promociones personalizadas y qué medidas debería aplicar antes de hacerlo.

## Situación

Comercializadora Norte propone utilizar la edad, ciudad y comportamiento de compra de sus clientes para enviarles promociones personalizadas.

## Preguntas y respuestas

### 1. ¿El hecho de que la organización ya tenga los datos significa automáticamente que puede utilizarlos para cualquier finalidad?

No. Que la empresa tenga almacenada esa información no significa que pueda utilizarla para cualquier cosa. Primero debe comprobar si esa nueva finalidad fue informada al cliente y si cuenta con una justificación válida para utilizar sus datos.

### 2. ¿Qué preguntas debería realizar la organización antes de implementar este tratamiento?

Debería preguntarse para qué necesita los datos, si los clientes fueron informados sobre las promociones, qué fundamento permite utilizarlos, qué información es realmente necesaria y cómo podrán oponerse a ese uso cuando corresponda.

También debería analizar quién tendrá acceso a la información y qué riesgos podría generar su utilización.

### 3. ¿Qué datos serían realmente necesarios?

Para enviar promociones podría necesitarse un medio de contacto, como el correo electrónico, y algunos datos relacionados con las preferencias del cliente.

La edad, ciudad y comportamiento de compra solamente deberían utilizarse cuando realmente sean necesarios para personalizar las promociones. No sería necesario consultar información como el RFC.

### 4. ¿Necesitaría el área de marketing acceso directo a clientes?

No necesariamente. Lo recomendable sería proporcionar una vista o conjunto de datos que contenga únicamente la información autorizada para marketing.

Así se evita que el departamento consulte información personal que no necesita para realizar sus actividades.

### 5. ¿Qué controles técnicos podrían limitar la información entregada?

Se podrían utilizar vistas SQL, roles con permisos específicos, restricciones de acceso, seudonimización y registros de auditoría.

También sería conveniente mantener una lista de clientes que no desean recibir promociones para evitar utilizar sus datos con esa finalidad.
