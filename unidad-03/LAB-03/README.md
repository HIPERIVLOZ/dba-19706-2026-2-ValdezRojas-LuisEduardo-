# LAB-03 — Políticas, gobierno de datos y evidencias

## Descripción

Este laboratorio reúne las actividades de gobierno de datos realizadas sobre la base de datos `comercial`, utilizando PostgreSQL y MongoDB.

Se trabajó con políticas de acceso, respaldo, retención, restauración, datos sensibles y cambios en producción. También se documentaron los responsables de los datos, el diccionario, el catálogo y los criterios de conservación.

## Estructura

- `EXPEDIENTE.md`: expediente de auditoría interna.
- `sql/`: consultas utilizadas durante las actividades.
- `politicas/`: seis políticas prácticas de datos.
- `evidencias/`: documentación y resultados de las actividades, además de las evidencias técnicas de PostgreSQL y MongoDB.

## Actividades realizadas

1. Verificación de calidad de datos.
2. Identificación de propietarios, custodios y usuarios.
3. Elaboración del diccionario de datos.
4. Elaboración del catálogo mínimo de datos.
5. Criterios de conservación de bitácoras.
6. Elaboración de políticas prácticas.
7. Registro y conciliación de cambios.
8. Integración de evidencias técnicas.
9. Elaboración del expediente de auditoría interna.

## Motores utilizados

- PostgreSQL: base de datos `comercial`.
- MongoDB: base de datos `comercial`.

## Evidencias

Las evidencias se encuentran organizadas en la carpeta `evidencias/`, incluyendo los documentos de calidad, responsables, diccionario, catálogo, conservación y conciliación.

También se incluyen los registros técnicos de PostgreSQL y MongoDB.

## Objetivo final

Integrar la información de los dos motores en un expediente que permita identificar los datos existentes, sus responsables, las modificaciones realizadas y las políticas que regulan su uso.
